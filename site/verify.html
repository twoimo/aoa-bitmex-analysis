재현 방법 Node 20+ · 의존성 없음

npm run fetch          # 원본 압축파일을 내려받아 .work/data/ 에 풉니다
npm run validate       # 이상치·중복 감사
npm run analyze        # 기술 통계
npm run insights       # 트레이더 지표
npm run verify:public  # BitMEX 공개 체결 아카이브와 trdMatchID 대조
npm run footprint      # 체결이 있던 가격대
npm run replay         # 일별 자산·포지션
npm run trades         # 체결 테이프 표본
npm run lessons        # 학습 단원·사례·퀴즈
npm run site           # 사이트 페이로드 재생성

공개 범위 무엇을 싣지 않았나

  • 원본 체결·지갑 CSV는 재배포하지 않습니다.
  • 모든 실행·주문·트랜잭션 식별자를 제거했습니다.
  • 날짜별 출금 원장은 일별 집계만 싣습니다.
  • 게시글 전문 대신 인용한 문장만 씁니다.
  • 공개된 값만 사이트에 들어갑니다. 원본 파일은 저장소에 없습니다.

분석 코드와 방법론은 저장소의 docs/ 에 있습니다.
